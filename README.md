# Eternity Soul ❤️ — Birthday Website

A romantic, interactive birthday website made with HTML, CSS, and JavaScript. It includes a memory gallery, profile photos, background music, a voice message, and animated birthday scenes.

> This is a static website. It does not require a backend server or database. It can be hosted with GitHub Pages.

## Features

- Responsive layout for phones and desktop browsers
- Birthday scenes and animations
- Photo memory gallery
- Profile photos
- Background music and voice message
- Interactive candle/blow feature (microphone permission may be required by the browser)

## Project files

Keep these files together in the repository root so that all relative paths continue to work:

- `index.html` — main website
- `photo1.png` … `photo20.png` — gallery photos
- `my-profile.png` — profile photo
- `her-profile.png` — profile photo
- `background-music.mp3` — background music
- `your-voice.m4a` — voice message

## Run locally

1. Download or clone this repository.
2. Keep all media files in the same folder as `index.html`.
3. Open `index.html` in a modern browser. For microphone-dependent features, run the page through a local web server or HTTPS and grant microphone permission when prompted.

## Host with GitHub Pages

1. Create a GitHub repository.
2. Upload the **contents** of this project folder (not an extra enclosing folder). `index.html` must be in the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment, then open the URL shown in the Pages settings. It will usually look like `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

GitHub Pages deployment may take a few minutes. Make sure the repository contains `index.html` at the selected publishing source's root.

## Personal media and privacy

The included photos, profile pictures, music, and voice recording may be personal. Only publish them if you have the right and permission to share them. A public GitHub repository and a GitHub Pages website can be viewed by anyone. If you want the code public but the personal media private, do not upload those media files to a public repository; note that the website will then need another appropriately accessible place to load them from.
